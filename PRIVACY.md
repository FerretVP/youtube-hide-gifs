# Privacy Policy — GIF Hider for YouTube

GIF Hider for YouTube does not collect, store, transmit, sell or share any personal or usage data.

The extension saves only two settings — the selected GIF hiding mode and the interface language — using Chrome's built-in storage (`chrome.storage.sync`). These settings stay in your browser and, if Chrome sync is enabled, are synced by Google between your own devices. The developer has no access to them.

The extension runs only on www.youtube.com. It reads the comment section only to find and hide GIF attachments on your screen, and it sends no data to any server.
